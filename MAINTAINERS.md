# Maintainers

This records who currently holds maintainer/repository-owner responsibility,
as defined in [GOVERNANCE.md](GOVERNANCE.md). It is the operational record
that document deliberately does not hardcode. Other project documents
("ask a repository owner," "ask the repository maintainer," "existing
maintainers") resolve here.

| GitHub handle | Scope |
|---|---|
| [@Frihat-dev](https://github.com/Frihat-dev) | Project owner; contracts, releases, repository and organization administration |
| [@seb-vv](https://github.com/seb-vv) | Architecture, documentation, and governance/release-policy authorship |

This list reflects current access and contribution history, not a
permanent roster. Update it in the same pull request that changes
maintainer access, and remove an entry when someone's access is revoked.
It has no bearing on asset-administrator identity, which is a separate,
token-level role (GOVERNANCE.md's "Roles and authority" table).

[.github/CODEOWNERS](.github/CODEOWNERS) mirrors this list for pull-request
review assignment. Keep the two in agreement.
